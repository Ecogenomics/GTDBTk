gplace.<domain>.json
====================

The placements generated by gPlace, in the jplace format (identical to pplacer's output).

Produced by
-----------
 * :ref:`commands/classify`
 * :ref:`commands/classify_wf`


Example
-------

.. code-block:: JSON

    {"tree":
      "((((((((((((((((((((((GB_GCA_002498125.1:0.17454{0}, ...",
      "placements":
      [
        {"p": [[0.00110044638583, 1579, 1, -3185321.84798, 0.00140069377318]],
          "nm": [["genome_2", 1]]
        },
        {"p": [[5.05004882812e-06, 1849, 1, -3541277.48905, 6.11351501465e-06]],
          "nm": [["genome_1", 1]]
        },
        {"p": [[0.00694927704923, 1579, 1, -2665208.65502, 0.0230770193005]],
          "nm": [["genome_3", 1]]
        }
      ], "metadata":
      {"invocation":
        "gplace place -m wag -j 3 -c \/release232\/pplacer\/gtdb_r232_ar53.refpkg -o classify_output\/classify\/intermediate_results\/gplace\/gplace.ar53.json align_output\/align\/gtdbtk.ar53.user_msa.fasta.gz"
      }, "version": 3, "fields":
      ["distal_length", "edge_num", "like_weight_ratio", "likelihood",
        "pendant_length"
      ]
    }
